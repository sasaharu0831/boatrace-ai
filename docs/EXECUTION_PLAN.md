# 3年・24場データ収集／検証 実行計画

対象期間: 2023-10-01〜2026-09-30
対象: 全国24場・全開催・全レース。

## 非交渉要件
- 会場横断でモデル、特徴量効果、校正、購入規則を作らない。24場を独立管理する。
- 予測特徴量は発走前に利用可能な情報だけに限定する。
- 開始10分後の天候は事後分析専用で、予測特徴量へ入れない。
- 生データ、正規化データ、特徴量、品質ログを分離する。
- 各行に取得日時、原典、パーサ版、品質フラグを残す。

## フェーズ
1. results / entries / payouts / 基本水面情報を3年・24場で収集する。
2. race_id=YYYYMMDD_jcd_rno と boat_no を基準に正規化・結合する。
3. 最寄り観測所の月次気象データを結合する。
4. 直近12か月の展示・直前情報を補完する。
5. 2026-10-01以降の pre_start / t0 / t_plus_10m スナップショットを定時収集する。
6. 締切30分前・10分前・3分前・直前のオッズ時系列を収集する。
7. 会場別ウォークフォワード検証と天候変動分析を行う。

## 時系列分割
- 学習: 2023-10-01〜2025-09-30
- 検証: 2025-10-01〜2026-03-31
- 最終テスト: 2026-04-01〜2026-09-30

## 保存物
- raw/: 原典取得物
- normalized/: races, entries, results, payouts, pre_race, water_conditions, weather_external
- curated/: 場別Parquetと分析CSV
- quality/: 欠損・重複・結合率・観測時刻差・取得失敗ログ
- reports/: 場別評価と天候分析
